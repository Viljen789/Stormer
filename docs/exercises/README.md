# Guided implementation exercises

These prepared exercises let the project owner implement Størmer's domain behavior while the repository supplies types, API boundaries, documentation, and behavioral specifications.
They intentionally contain exercise holes rather than reference solutions.

| Exercise | Focus | Guide | Roadmap use |
| --- | --- | --- | --- |
| 0001 | Physical dimensions, typed expression IDs, model construction, and harmonic-oscillator IR | [Dimensions and model IR](0001-dimensions-and-model-ir.md) | Parked across Milestones 2 and 3 |
| 0002 | Checked derivatives, Euler, trajectories, RK4, and a damped-oscillator capstone | [Numerical runtime](0002-numerical-runtime.md) | Current Milestone 1 scaffold |

Exercise numbers record scaffold creation order rather than the order in the rolling roadmap.
Check `STATUS.md` before starting a prepared guide.

Run `cargo test --workspace` for the normal green baseline.
Run a named ignored test from an exercise guide when working on its corresponding TODO.
